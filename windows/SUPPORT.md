# Windows 原生版 支持矩阵

方案文档第 17 节「阶段 5 试点收口」的支持矩阵，按第 471 行的一期正式范围写清。三档：首发支持、真机回归后才标注、不列首发。

> 「一期正式范围」是发布目标，不是今天已经全部验证的承诺。凡未真机回归的项一律按「未验证」对待，不开放正式承诺（文档 467 行「每项运行证据完整，未验证功能不开放正式承诺」）。当前分支只含 Phase 0 + Phase 1，其余阶段在未合并分支。

## 首发支持（一期正式范围）

| 能力 | 首发状态 | 当前验证 |
|---|---|---|
| Windows 11 x64 | 首发支持 | 本机 11 Pro 26100 上 Phase 0（Job Object 监督 + Named Pipe 控制面骨架）与 Phase 1（内核跨平台）已真机验证 |
| 本地单用户可信模式（标准模式） | 首发支持 | 只降低事故概率，不隔离同用户恶意（文档 10.2）；严格模式是后续独立里程碑 |
| Claude / Codex 经能力探测的闭环 | 首发支持（目标） | 能力探测本会话只做假 CLI 自检；真实 CLI 闭环、session 续接、费用增量均 NOT_RUN |
| 明确审批的受控动作 | 首发支持（目标） | effect 审批卡在未合并分支（Phase 3），本分支未含 |
| 登录常驻 | 首发支持（目标） | Task Scheduler 登录任务在未合并分支（Phase 4），真实部署 NOT_RUN |
| CLI / 托盘 | 首发支持（目标） | 管理页/托盘骨架在未合并分支（Phase 4），可达性 NOT_RUN |
| 备份 / 更新 | 首发支持（目标） | installer/release 最小结构在未合并分支（Phase 4），干净 VM 非 admin 全闭环 NOT_RUN |
